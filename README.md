# ⚖️ LexAI – Legal Document Analyzer

LexAI is a web-based legal assistant that helps users analyze legal documents, ask legal-related questions, and generate simplified insights from uploaded files or pasted text.

The project provides an interactive chatbot-style interface with document upload support and report generation features.

---

## ✨ Features

- 💬 Legal chatbot interface
- 📄 Upload and analyze PDF documents
- 📊 Generate analysis reports
- 🌙 Dark mode support
- 🎤 Voice input option
- ⬇ Download generated analysis
- 🧠 Simple legal document understanding

---

## 🚀 Installation

### Clone the repository

```bash

```

### Open project

```bash
cd LexAI
```

### Install dependencies

```bash
pip install flask
```

### Run the application

```bash

```
